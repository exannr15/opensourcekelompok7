# Dokumentasi Anggota Kelompok 7

## Tujuan
Mendokumentasikan anggota dan peran dalam proyek kolaborasi Open Source.

## Daftar Anggota
- Exan Nabil Rifai: Ketua dan pengelola repository.
- Cikal: Kontributor dokumentasi.
- Reyhan: Kontributor pengembangan.
- Fazal: Pengujian dan pemeriksaan hasil.

## Alur Kolaborasi
1. Membuat Issue.
2. Mengembangkan perubahan pada branch.
3. Mengajukan Pull Request.
4. Melakukan Code Review.
5. Menggabungkan perubahan ke main.
