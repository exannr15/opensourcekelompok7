# Kolaborasi Open Source Kelompok 7

Repository ini dibuat untuk memenuhi tugas Pertemuan 7 mata kuliah Open Source.

## Tujuan
Menerapkan kolaborasi tim menggunakan GitHub melalui Issue Tracking, Fork, Branch, Pull Request, dan Code Review.

## Anggota Kelompok
- Anggota 1 : Exan Nabil Rifai
- Anggota 2: Cikal fachri amanta
- Anggota 3: Alfatir faza kesumo
- Anggota 4: Reyhan samudera wahid

## Kegiatan
- Membuat dan menyelesaikan Issue
- Melakukan Fork dan Clone repository
- Membuat Branch dan perubahan kode
- Mengajukan Pull Request
- Melakukan Code Review dan Merge
